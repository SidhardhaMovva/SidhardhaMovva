# Sidhardha Movva

Building AI agents and LLM applications.

I like building AI that has to hold up in the real world — an agent answering a clinic's phone calls, a retrieval pipeline whose quality you can actually measure, tools that help other agents work together instead of overwriting each other. The parts I care about most are the unglamorous ones: evaluating whether the output is right, handling failure gracefully, and knowing when the system should say it doesn't know.

### Featured projects

- **Aria** — AI voice receptionist for medical clinics · [aria-voice-agent](https://github.com/SidhardhaMovva/aria-voice-agent)
- **Coord** — coordination layer for parallel AI coding agents · [coord](https://github.com/SidhardhaMovva/coord)
- **LLM Gateway** — one API for OpenAI and Anthropic, with semantic caching, rate limiting, and fallback · [llm-gateway](https://github.com/SidhardhaMovva/llm-gateway)
- **RAG Eval Pipeline** — measurable RAG: chunking comparison, Recall@k and MRR, grounded answers that abstain on weak evidence · [rag-eval-pipeline](https://github.com/SidhardhaMovva/rag-eval-pipeline)
- **AI Workflow Automation** — DAG workflows with retries, branching, and human-approval steps · [AI-Workflow-Automation-Platform](https://github.com/SidhardhaMovva/AI-Workflow-Automation-Platform)
- **ML Model Serving** — model serving with Prometheus metrics, structured logging, and Docker deployment · [ML-Model-Serving-Platform-with-Observability-](https://github.com/SidhardhaMovva/ML-Model-Serving-Platform-with-Observability-)
